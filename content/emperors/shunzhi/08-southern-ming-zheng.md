# 顺治卷 08：南明与郑氏

状态：`E1 单源回查`
范围：只处理已经打开的《清史稿》卷4、卷5本纪里的南明年号、破城、郑成功各句。南明己方实录、郑氏档案、外国记录本次未开。本纪称「故明某某」，是清史稿的用字，不作对方政权的自我定名。

## 先说结论

本纪把南方政权按出现顺序写下，不收成一个「南明」事件。福王朱由崧改元弘光，在二年五月南京降后被执。唐王在福建，三年十一月本纪写斩于汀州。鲁王在浙江。桂王由榔在湖广、两广一线活动，本纪用「桂王」称呼。郑成功从七年九月「寇潮州」起反复出现，十六年犯江宁，八月败于高山。

「扬州十日」是后出笔记用语，本纪二年四月只写克扬州、史可法不屈杀之。见 [扬州](#/site/QH-ST-0018)。死亡数字冲突见 `QH-ST-0024`，本章不取一个数。

## 怎么读这件事

本纪是京师视角的后出编年。破城日能落到干支，不等于已经打开南明诏书或郑氏海澄文书。弘光、隆武、永历这些年号，本纪有的写出（弘光、永历），有的只写王爵。缺的一层标待核，不补。

## 福王 / 弘光

卷4元年七月：故明福王朱由崧即位江南，改元弘光，史可法驻扬州督师。壬子，睿亲王以书致史可法，劝其主削号归藩；可法答书不屈。书信全文在卷218，本章不整篇重录。

二年四月庚午师至扬州，谕降不从；丁丑克扬州，史可法不屈，杀之。五月丙申师至南京，福王遁太平，赵之龙、王铎、钱谦益等迎降。六月辛酉，田雄、马得功执福王来献。

不能把钱谦益迎降写成已经核过的每人降表。不能把「扬州十日」写成官方事件名。

## 唐王、鲁王、桂王

三年正月己巳，故明唐王朱聿钊兵犯徽州；十一月癸卯朔，博洛军败黄鸣骏于仙霞关，本纪写故明唐王朱聿钊走汀州，追斩之，福建平。四年二月乙未，朱聿钊弟聿鐭僭号绍武，据广州，佟养甲、李成栋斩聿鐭，广州平。

鲁王：二年十月，本纪写鲁王朱彝垓据浙江；三年五月乙丑图赖等败方国安于钱塘，鲁王遁保台州。

桂王：四年十二月丙戌大军收湖南，本纪写桂王由榔走。五年以后湖广、两广战事，本纪多次出现何腾蛟、李定国、孙可望。六年八月丙午，济尔哈朗克湘潭，获何腾蛟，不屈，杀之。十年以后李定国仍在本纪出现。逐城日程未拆完，不写成「南明已灭于某年」——本纪十八年正月世祖崩时，桂王一线仍未在已开句里写死。

四年七月丁巳，郧阳贼王光代「用永历年号」。本纪这里写出了永历年号，但没有在同条给桂王即位日。

## 郑成功

本纪已开的郑氏句，按年排，不作海战复原：

| 纪年 | 本纪动作 |
|---|---|
| 七年九月甲寅 | 故明将郑成功寇潮州，王邦俊击走之 |
| 九年七月丙子 | 浙闽总督陈锦征郑成功，至漳州，为其下所杀 |
| 十年十一月戊戌 | 郑成功不受爵，优谕答之 |
| 十年十二月丙戌 | 郑成功犯吴淞，官军击走之 |
| 十一年正月—三月 | 犯崇明、靖江、泰兴、金山 |
| 十一年十二月乙亥 | 陷漳州，围泉州；壬申命济度征郑成功 |
| 十二年—十三年 | 犯舟山、台州；黄梧以海澄来降，封海澄公 |
| 十六年六月壬子 | 陷镇江府 |
| 十六年七月丙子 | 犯江宁 |
| 十六年八月己丑朔 | 江南官军破之于高山，成功败遁 |
| 十七年七月壬午 | 以罗托为安南将军，征郑成功 |

十六年八月条写成功拥师十余万、战舰数千、抵江宁城外列八十三营。这是本纪战报，不是郑氏自己的营册。康熙二十二年取台湾不在本章。
