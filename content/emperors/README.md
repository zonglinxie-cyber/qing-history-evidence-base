# 十二帝第一版研究卡

本目录是"十二帝骨架＋康熙样卷"的可读入口。当前完整结构化内容见 `data/qing-emperor-research-cards.csv`，画像见 `data/emperor-portraits.csv`，来源见 `data/qing-emperor-source-index.csv`，御制与敕编文献总目见 `data/imperial-works.csv`。本地网页工作台见 `site/`。

## 当前能用到什么程度

- 十二帝均有统一人物 ID、在位口径、父母、主要后妃与子女候选、重大事件骨架、争议边界、《清史稿》本纪和实录/政纪卷数；
- 十二帝均有一件逐文件核过公版标示的明黄朝服默认像；康熙便服、雍正扮装、道光园居、咸丰读书、同治写字、光绪常服照、溥仪退位后照片作为其他真迹进入人物页；
- 所有家庭字段仍是"索引级候选"，不是完成玉牒核验的最终关系树；
- 当前证据状态统一为 `S二手索引 / M1 AI回查`，后续必须拆成原子主张，回到具体《实录》卷条、档案或玉牒版本；
- 十二帝均有一篇索引级可读章（`#/chapter/<slug>`），接到人物页「从这几条读」。康熙另有储位、四后、皇子、皇女、西学文治诸篇；雍正另有本纪切片、改革、文字狱与御制诸篇；其余十帝各新增「文治与著述」章。索引章不拆原子主张。
- **新增：** 十二帝的御制著述、敕编文献和实录详情已收入 `data/imperial-works.csv`（54条），各帝均有一篇「文治与著述」章节（`#/chapter/<slug>-02`）。
