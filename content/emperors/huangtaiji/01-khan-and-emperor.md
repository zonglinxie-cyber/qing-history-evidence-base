# 汗位与帝位：1626 到 1636

状态：`S二手索引 / C 来源已拆 / M1 AI回查`  
范围：已打开《清史稿》卷2、卷3太宗本纪短引。后出本纪，不作终审。汗位与帝位必须分年。

## 先说结论

1626 年接汗位，定翌年 1627 改元天聪；1636 年称帝，改国号大清，改元崇德。**继汗位、改元与称帝是不同动作**，不能写成一次即位。从汗到帝的十年，是后金政权制度转型的关键时期。继位是推举还是预定，猝死原因，实录有没有删改，目前都还是索引。

## 本纪怎么写

卷2把1626年写成即位于沈阳、明年改元天聪。卷3才写1636年定号大清。

#### 读这一句

**原文**　定有天下之號曰大清，改元崇德

**今译**　定天下的国号为大清，改元崇德。

**当时**　《清史稿》卷3，崇德元年四月乙酉。距继汗位已经十年。

**今天还读**　读它可以把汗位、改元、称帝拆成三步。

**不能写成**　不能把1636年的大清倒写到努尔哈赤头上；不能把继汗位写成已经称帝。

## 骨架

1. **1626 汗位。** 父死之后接的是汗，不是后来的清帝位。继位程序在天聪朝实录中的记载，与后来崇德朝的制度叙述之间可能存在差异，尚未核查。
2. **天聪改革。** 研究卡记强化汗权、天聪五年（1631）仿明制设六部、天聪十年（1636）文馆改内三院。精确条文和月日未回《太宗实录》。这套制度框架后来被顺治、康熙朝继承和发展，是清朝中央集权的起点。
3. **蒙古八旗、汉军八旗。** 与满洲八旗分开记，不要合成「八旗从一开始就是三套」。八旗的扩充不是一次完成的，每一次扩编都对应着新的归附群体。
4. **改女真为满洲、1636 称帝改国号。** 国号大清从这一年算，不能倒写到努尔哈赤头上。改族名和改国号是同一政治动作的两面：告别部落时代，建立王朝正统。
5. **两次对朝鲜用兵、松锦之战。** 第一次是 1627 年丁卯之役，第二次是 1636—1637 年丙子之役，不能把“两征”压成 1636 年的一场战争。入关前的军事骨架与战报尚未逐条拆解。松锦之后，入关的局面才打开；打开不等于已经入关。
6. **猝死。** 原因未核。当时的皇后是孝端文皇后博尔济吉特氏。孝庄是后世追尊，当时不是皇后。福临是后来的顺治，不要把世祖庙号提前。「无疾而终」的官书记载，在后世研究中多有质疑。

宫在沈阳，陵是昭陵，俗称北陵。见 [沈阳故宫](#/site/QH-ST-0006)、[昭陵](#/site/QH-ST-0015)。宁远是其父受挫处，见 [宁远之战](#/site/QH-ST-0003)。

## 边界

- 1626 继汗位、1627 改元天聪与 1636 称帝改元崇德必须分栏。
- 「皇太极」词源与原始满文未核。
- 不要把后来的太宗庙号，写成他在天聪元年已经使用的称号。
- 继位是推举还是预定，实录有没有删改，都还没回原文。
- 松锦之战后，明军关外主力尽失，但山海关仍在明军手中。入关的最后一步，要等到顺治朝由吴三桂开关。
