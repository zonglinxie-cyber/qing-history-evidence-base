# 嘉庆卷 08：本纪里的「教匪」，不是一句白莲教

状态：`S 二手转述`
范围：只处理已经打开的维基文库《清史稿》卷16本纪中的「教匪」起止句。户部军费档案、《钦定平定教匪纪略》、《仁宗实录》日页、《圣武记》尚未列出逐条依据，不在本章范围内写成已核。本纪用「教匪」，「白莲教」是后出归类，二者不得互改。

## 先说结论

卷16把这场战争写成跨省、跨年的「教匪」军事编年，不是一个已经核清组织形态的教门史。元年正月已见「湖北枝江、宜都教匪起」；同年二月当阳教匪起；其后四川、陕西、甘肃交错出现。七年十二月，本纪书额勒登保、德楞泰、勒保、惠龄、吴熊光「会报川、陕、楚教匪荡平」，并分封爵赏。

通行说法常作「元年爆发、九年平定、军费约两亿两」。元年起事与本纪方向一致；「九年」和「两亿两」本章未回户部报销与实录九年条，不升格。本纪七年十二月已经写荡平，八年仍有剿捕余匪、阵亡恤典，说明「会报荡平」不等于战场上再无一人。

## 本纪骨架（只到已开句）

| 纪年 | 本纪动作 | 证据边界 |
|---|---|---|
| 嘉庆元年正月 | 湖北枝江、宜都教匪起 | 起事地点是本纪用语，不是教门自称 |
| 元年二月 | 湖北当阳教匪起，戕官；惠龄奏获聂杰人 | 「获」是奏报层 |
| 元年四月 | 命宜绵、永保、恒瑞、孙士毅等分剿湖北教匪 | 分路是官书编排 |
| 二年正月 | 四川教匪徐添德侵扰达州、东乡 | 本纪此时已入川 |
| 二年五月 | 姚之富等抢渡汉江入川；罢总统，改宜绵总统 | 人事处分与战况同条，不合成因果鉴定 |
| 三年八月 | 以获教匪王三槐功，晋勒保及和珅公爵，福长安侯爵 | 军功封爵在训政期，太上皇仍在 |
| 四年正月亲政后 | 特诏申明军纪；命勒保为经略 | 与和珅案同月，两件事不要压成「反腐带动平教」 |
| 四年二月 | 诏教匪迫胁良民，「欲逃无归，归亦无食」，令筹招抚 | 这是招抚政策文本，不是人数统计 |
| 五年七月 | 马慧裕奏获传教首犯刘之协，解京诛之 | 本纪称「传教首犯」，不自动等于全场教主 |
| 七年七月 | 额勒登保奏获苟文明；谕「教匪起事诸犯，只余此贼」 | 「只余此贼」是当日谕旨口径 |
| 七年十二月 | 会报川、陕、楚教匪荡平，封侯伯有差 | 会报不等于逐县清册 |

元年正月句：

> 湖北枝江、宜都教匪起。

七年十二月句：

> 詔額勒登保、德楞泰、勒保、惠齡、吳熊光會報川、陝、楚教匪蕩平。封額勒登保、德楞泰一等侯，勒保一等伯，明亮一等男，賽沖阿、楊遇春以次封賚。

四年二月招抚诏：

> 自教匪滋事以來，迫脅良民，焚毀田舍。民非甘心從賊，欲逃無歸，歸亦無食。

## 怎么读这件事

先拆三层。第一层是本纪的军事编年：何省起事、何人奏获、何人封爵。第二层是官方归类：「教匪」「邪匪」「传教首犯」是清朝文书的敌人名称，不能直接当成参与者的自我认同。第三层是后出综述：「白莲教起义」「嘉庆中衰」是后来的题目，本纪没有这两个词。

训政三年（元年至四年正月）的军功封爵仍在太上皇在世时颁发。三年八月王三槐功同时晋勒保与和珅公爵。把这场战争写成「嘉庆亲政后才开始打」，与本纪年份相反。

八年以后本纪仍有余匪、乡勇入伍、宁陕新兵滋事。卷16十二年正月诏回顾「从前剿办邪匪，乡勇过多」，说明善后被本纪单独写成另一件事，不并进七年十二月的「荡平」句。

## 边界

- 不取「白莲教」三字覆盖本纪「教匪」。
- 军费约两亿两是通行说法，未见户部档案，不比较数量级。
- 教门内部的经卷、教首谱系、地方会社，本章未开私撰与档案，拒答。
- 《钦定平定教匪纪略》只登记书名入口，未拆卷。
- 不得把七年十二月会报写成九年才平；也不得把会报写成战事当日结束。
