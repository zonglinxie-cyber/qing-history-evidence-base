# 十帝争议清单（第一版 · 索引级）

> 人文兴趣与争议组第一版产出。范围：康熙、雍正之外的其余十帝（康雍争议已拆入各卷冲突组）。
>
> **分级定义**：
> - **学术**：史料间有互斥说法，须并列展示、不裁决，标证据状态（已证/待核/存疑/目前未证实/否定）。“目前未证实”是公开材料仍不足；“否定”只用于已有直接反证的命题，两者不能互换。
> - **野史**：民间流传、无一手证据，不升格为事实，仅作对照。
> - **影视**：清宫剧/二创常见误读，须澄清。
>
> 数据源：`data/qing-emperor-research-cards.csv`「必须保留的争议或边界」列。红线：不把野史包装成「另一种同等可能的历史」（章程）。
