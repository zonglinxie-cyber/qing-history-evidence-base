## 一、什么时候必须建组

出现互斥说法，且两边都有本库承认的出处（实录／本纪／列传／档案汇编／已登记研究），就建组，**不要在专章里择一抹平**。

不必建组：只有一条后出传闻、对照栏已经够用（许多 `side-lanes` 野史条）。传闻升格到「有专文对打」，再补组。

---

## 二、怎么建一行（给皇帝代理）

1. `conflict_set_id`：`QH-CF-<朝缩写>-<议题>`，朝缩写与现组一致（KX／YZ／QL／JQ）。新朝用 DG／XF／TZ／GX／XT／NH／HT／SZ，先在本页待办里登记，避免撞号。  
2. `议题`、`冲突维度`（时间／客体／写法／卷次等）。  
3. `现行编辑判断`：优先「不择一／两说并存／分层保存」。  
4. `判断依据主张`：填已有主张 ID。引用了争议表达的主张**必须挂组**——干支组现在缺挂 QH-A-QL-0002、QH-A-JQ-0002（docs/23 §4），嘉庆／乾隆代理补上即可。  
5. `保留意见`：写清什么不准覆盖什么。  
6. `研究综述`／`主要论著`／`综述状态`：按 docs/23 四条诚实边界。**页码一律不编。** 无专文就写 `待补` 并写「须查什么」。  
7. 专章正文只写「见冲突组 ID」，不要把学术史段落再抄一遍。

校验：`npm run validate` 会提示「有现行编辑判断却无保留意见」、空组未登记待补面。

## 四、和勘误、黄金问题、侧栏

| 动作 | 入口 |
|---|---|
| 发现组内某条写错 | `npm run errata -- --loc QH-CF-…`（`docs/25`） |
| 发现主张该挂未挂 | 改 `source-claims` 的冲突组 ID；也可先勘误 |
| 把争议收进验收集 | `golden-questions`，类别用「版本冲突」；后八帝现为 0 题，提案见 `golden-questions-gap.csv` |
| 只要野史对照、不互斥 | `side-lanes` 野史栏，不必建组 |

十帝争议清单（`disputes/README.md`）仍是索引。康雍已拆组的，应链到上表 ID，不要在清单里另写一套「学术／待核」却不给组号——这是下一步，本页先把入口立住。
