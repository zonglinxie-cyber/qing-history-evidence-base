# 雍正卷 04：《大义觉迷录》——自辩、颁旨与缴书

状态：`S 二手转述 / E1 单源回查 / C 来源冲突 / M1 AI 回查 / 待 H1 抽查`  
范围：维基文库《大义觉迷录》只拆卷一华夷、卷一传位场面、卷三改诏传闻、卷三驳语四条短引，不镜像全书。实录已钉世宗卷81五月二十一日、卷86九月十二日、卷87十月六日，高宗卷5十月十九日、卷9十二月十九日。会典、案档原供、销毁续旨未开。自辩不作继位终审。不得写「已证伪改诏」。

## 先说结论

《大义觉迷录》是御制谕旨与供词的刊本汇编，不是实录，也不是案档原件。书里的华夷论、传位场面和改诏驳语，都是雍正要人看见的自辩。改诏那一句在书里是耿六格转述太监谈论，不是曾静亲笔原供。

官书这边，已经打开的《世宗实录》用「先是」追记投书，用九月十二日把华夷上谕颁到各府州县，用十月六日写下「不行诛戮」。全书名《大义觉迷录》在已打开的七年九月至十二月各条里没有出现。乾隆这边，十三年十月十九日是停讲解、缴原书、候再降旨，不是销毁句；十二月十九日是凌迟处死。本纪把治罪写在十月壬申、把结局写成磔于市，与实录不是同一套字。分层登记，不择一。

## 怎么读这件事

1. **刊本不是实录。** 觉迷录证明这些话被编进官刻本。它不覆盖《圣祖实录》的御榻名单，也不把改诏写成已经裁断的事实。
2. **颁旨不是自动等于刊书。** 七年九月十二日实录写的是「通行颁布」这一道上谕。书名要等书名自己出现，或等后来官书承认「颁发原书」。
3. **缴书不是销毁。** 十三年十月十九日只写停讲解、彙送礼部、候旨。续旨未钉，不能补写成烧书完成。
4. **传闻和驳语必须两行。** 书里先记下「十」改「于」，再写下「焉有不遭诛殛」。两句都在，不等于后一句已经证伪前一句。

## 骨架

1. **七年五月二十一日：实录用「先是」追记投书。** 湖南靖州人曾静遣徒张熙，诡名投书川陕总督岳钟琪。岳钟琪具折并逆书奏闻。下文转到吕留良评点时文、日记，命九卿会议治罪吕氏。这是案发的官书叙事，不是六年九月当日条，也不是案档原供。{{claim:QH-A-YZ-0051}}

> 先是、湖南靖州人曾靜、因考試劣等。家居憤鬱。忽圖叛逆。遣其徒張熙、詭名投書於川陝總督岳鍾琪勸以同謀舉事。

本纪九同一天也写「先是，岳钟琪疏言有湖南人张熙投递逆书」。后出本纪不作终审。{{claim:QH-A-YZ-0054}}

2. **书里怎么讲华夷。** 卷一把满洲比作籍贯，并引舜为东夷、文王为西夷。这是刊本里的御制口径。{{claim:QH-A-YZ-0047}}

> 本朝之為滿洲，猶中國之有籍貫。舜為東夷之人，文王為西夷之人，曾何損於聖德乎？

3. **七年九月十二日：实录颁的是这道华夷旨。** 同日第1/1条把「本朝之为满洲，犹中国之有籍贯」写进上谕，并令通行颁布天下各府州县远乡僻壤。全文没有《大义觉迷录》书名。{{claim:QH-A-YZ-0052}}

> 著將朕諭旨、通行頒布天下各府州縣遠鄉僻壤。俾讀書士子、及鄉曲小民共知之

4. **书里怎么讲传位场面。** 卷一说皇考先命允祉、允祐、阿其那、塞思黑、允䄉、允祹、允祥和原任理藩院尚书隆科多至御榻前，口谕皇四子继位；又写恒亲王未在京师，庄亲王等在寝宫外，朕驰至，戌时上宾，隆科多乃述遗诏。名单仍是七位皇子加隆科多，衔名用的是后来的亲王号和阿其那、塞思黑。不能用这一段改写《圣祖实录》卷300的淳郡王、贝勒、贝子和「理藩院尚书」。{{claim:QH-A-YZ-0048}}

> 皇考命誠親王允祉、淳親王允祐、阿其那、塞思黑、允䄉、公允祹、怡親王允祥、原任理藩院尚書隆科多至御榻前，諭曰：「皇四子人品貴重，深肖朕躬，必能克承大統，著繼朕即皇帝位。」

{{conflict:QH-CF-YZ-DYJML-SCENE|觉迷录传位场面与圣祖实录御榻衔名}}

5. **七年十月六日：九卿请诛，上谕不诛。** 怡亲王、大学士、九卿等合词请将曾静、张熙即行正法。上谕承认情罪万无可赦，又说「不行诛戮者实有隐衷」，并称可以宽宥其罪。同日第2/4条转到李绂、蔡珽，不是刊书条。{{claim:QH-A-YZ-0053}}

> 今日諸臣、合詞請誅曾靜張熙。……但朕之不行誅戮者。實有隱衷。……可以寬宥其罪。

6. **书里的改诏传闻，和书里的驳语，是两行。** 卷三记耿精忠之孙耿六格供称：在三姓地方八宝家中，听太监于义、何玉柱向八宝女人谈论「圣祖皇帝原传十四阿哥允禵天下，皇上将『十』字改为『于』字」。同段还有人参汤、太后撞死等流言。这是刊本转述的供称，不是曾静原供，也不是案档原件。{{claim:QH-A-YZ-0049}}

> 訊據逆賊耿精忠之孫耿六格供稱……聖祖皇帝原傳十四阿哥允禵天下，皇上將「十」字改為「于」字。

驳语在附近，仍是自辩：

> 今乃云皇考欲傳位於允禵，隆科多更改遺詔，傳位於朕……焉有不遭上帝皇考之誅殛者乎！

#### 读这一句

**原文**　聖祖皇帝原傳十四阿哥允禵天下，皇上將「十」字改為「于」字。

**今译**　圣祖皇帝本来要把天下传给十四阿哥允禵，皇上把「十」字改成了「于」字。

**当时**　维基文库《大义觉迷录》卷三。书中记为耿六格供称转述太监谈论。标点排印，不是原刻本，更不是案档。

**今天还读**　读它可以看见这句谣言怎样被写进官刻本。它解释谣言为什么流传，不负责宣布谣言已经死了。

**不能写成**　不能写成曾静亲口原供；不能写成已经证伪改诏；不能用这一句覆盖《圣祖实录》的口谕和遗诏。

7. **十三年十月十九日：停讲解，缴原书，候旨。** 高宗实录卷5第1/5条：「大义觉迷录，著照尚书徐本所请，停其讲解。其颁发原书，著该督抚彙送礼部，候朕再降谕旨。」这是目前打开的、点出书名的实录条。它承认曾经颁发原书，并下令停讲、缴回。它没有写销毁、禁毁或烧板。续旨未钉。{{claim:QH-A-QL-0007}}

> 大義覺迷錄、著照尚書徐本所請。停其講解。其頒發原書。著該督撫彙送禮部。候朕再降諭旨。

同月七日壬申，实录卷4第1/7条是豁免江南等省漕项芦课学租；其余六条也没有曾静。{{claim:QH-A-QL-0011}}

本纪同日写「命治曾静、张熙罪」。那一句只在《清史稿》高宗本纪，且属于雍正十三年十月，不是乾隆元年。{{claim:QH-A-QL-0009}}

## 边界

- 觉迷录自辩不作继位终审。继位见 `#/chapter/yongzheng-01`、`#/chapter/kangxi-01` 与对照栏。
- 不得写「已证伪改诏」。满汉书写习惯也不支持把「十改于」当成唯一解释。
- 曾静口供在书中的样子，不等于案档原件。耿六格供称更不是曾静原供。
- 七年九月颁华夷旨，不等于已经钉到「刊成《大义觉迷录》」那一日。已打开的七年九月至十二月未见书名。
- 十三年十月十九日是停讲、缴书、候旨。不得改写成销毁完成。
- 治罪、凌迟、磔市都在雍正十三年冬，不在乾隆元年。
- 吕四娘目前不可证，见 `#/lane/QH-L-0009`。
- 仓库不保存全书。入口见 `#/works` 之 QH-W-024。
