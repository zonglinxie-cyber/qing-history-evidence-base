# 朱批、上谕、诏书：文献类型说明

> 本页是文种分层，不是某帝的朱批释文。提案词表：`data/patches/cross-cutting/document-type-vocab.csv`。
> 图像层的教训见 `docs/26`：16 件「朱批奏折」并不都画得出朱批区。

词表目前没有 `document_genre`。主张谓词已有 `issued_edict`、`reported_in_memorial`、`issued_proclamation` 等，但折、批、谕、诏在数据里仍常挤在「奏折朱批」一个展示角色下。

---

## 一、文种怎么分

| 文种 | 是什么 | 不是什么 | 本库已有的例子 |
|---|---|---|---|
| 奏折 | 臣工进呈的黑字（或墨笔）折件 | 皇帝的话 | 杨琳奏、马会伯摺、长龄奏 |
| 朱批 | 皇帝写在折件上的朱笔 | 印、引谕、全篇朱笔诏 | E04H、E05I、E07B、E11C 能画出批／文两层 |
| 朱谕 | 不批在折上、朱笔直接写的谕 | 折上的「知道了」 | reading 所收咸丰赞襄遗诏标「朱谕」 |
| 上谕 | 以皇帝名义颁发的指令 | 原件本身 | 实录所载上谕是官修层 |
| 诏书 | 即位、大赦、遗诏、退位等礼仪文书 | 朱批 | 载湉入承大统诏 E10C；退位诏 E12C |
| 懿旨 | 皇太后名义 | 皇帝上谕 | 同治亲政诏里的「谨遵慈命」须分层 |
| 廷寄 | 军机处封发的寄信上谕 | 内阁明发 | 本库尚无独立文种行 |
| 起居注 | 逐日记注 | 实录 | `QH-W-056`–`064` 皆 L0 |
| 实录 | 嗣皇帝敕修编年 | 当天日记 | 各朝 `imperial-works` |
| 圣训 | 分类辑录谕旨 | 当朝自撰全书 | 序多嗣皇帝所撰 |
| 御制 | 以皇帝署名的诗文论序 | 客观事实 | 《大义觉迷录》只作「当时这样说」 |
| 敕撰 | 奉敕由馆臣编 | 皇帝亲笔 | 《康熙字典》《四库全书》 |

## 二、红、印、批

`docs/26` 逐件看过本地图以后：

- 有「左列朱批＋黑字正文」的，才画朱批区。  
- 道光、咸丰两件是**全篇朱笔**，改标「朱笔全文」，不能假装有黑字层。  
- 载湉入承大统诏是黑字诏文＋用宝；多尔衮令旨是黑字＋钤印。**印不是朱批。**  
- 《硃批谕旨》御制序是刻本卷首，不是某件原折的批。  
- 杨廷璋铜板图样摺「旨」起两列是引谕，不是本件朱批。

绑定率低：缺的是与折件内容对应的主张，不是再画一个框。建主张须有逐字引文与卷页／档号（`docs/04` §2）。

## 三、刻本、汇编、原件

| 层 | 例子 | 用法 |
|---|---|---|
| 原折影像 | 台北故宫宫中档；本库多件仅入口、无本地图 | 黄：元数据＋外链 |
| 已刊汇编 | 《雍正朝汉文朱批奏折汇编》等，`docs/24` SRC-060–066 | 同时代·官方；不镜像 |
| 选刻本 | 《硃批谕旨》360 卷，乾隆三年选刻 | 有删选，不能等同原折 |
| 实录转写 | 「上谕……」 | 官修层，日期与措辞以该卷为准 |
| 后出转载 | 《清史稿》本纪录诏 | 不得作终审 |

reading 里的十帝文献（七大恨、遗诏、禅位诏、退位诏等）是**原文／译／评**分栏的索引稿，多数尚未钉稳定卷页。评栏不是主张。

## 四、皇帝代理写朱批时

1. 先标文种，再标朝次。  
2. 释文与图像分区分开：没有朱砂就不要标朱批区。  
3. 懿旨的主体是太后，不要写成皇帝下旨。  
4. 满文朱批用译编时，注明现代整理层（SRC-061、SRC-065）。  
5. 专章可以引用本页的分层，不要在各帝目录里另造一套文种名。
