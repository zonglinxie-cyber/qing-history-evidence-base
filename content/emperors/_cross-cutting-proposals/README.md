# 横切提案（给皇帝代理）

数据提案在仓库 `data/patches/cross-cutting/`。这里只说明**怎么接**，不重复 `docs/27` 的矩阵。

1. 需要新人物时：先在人物档提案里写规范名与待核主张，**不要自造 `QH-P-*`**。总索引里「研究卡提及、无档」的名字（多尔衮、孝庄、褚英、和孝公主等）都停在这一步。
2. 需要新史迹时：先有可核的 Commons 文件页和坐标，再提案 `historic-sites` 行。慕陵提案 `QH-ST-0052` 已有图、经纬约数；惠陵 `QH-ST-0049` 仍无专照，禁止空行入库。太庙仍禁止空行。权利台账见本目录 `tomb-source-rights-ledger.csv`。
3. 需要新黄金问题／侧栏：可参考 `golden-questions-gap.csv`、`side-lanes-gap.csv` 的表头与口气，绑定已有章节或主张。
4. 专章正文仍写在 `content/emperors/<slug>/`，不要写进本目录。

5. 十二帝近臣／对手网：可读章与跨帝交叉见 `people-network-index.md`。AI 制度示意图见 `ai-schematics/`，台账 `people-network-source-rights-ledger.csv`。仍不要自造 `QH-P-*`。
