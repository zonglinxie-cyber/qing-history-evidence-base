## 二、清朝六期脉络

### 第 1 期 · 创业立国（1583—1644）｜努尔哈赤 · 皇太极

**一句话**：从建州女真一部，经后金到大清，用两代人完成「政权」与「国号」的创立。

- 1583 十三副遗甲起兵；1616 努尔哈赤称汗建后金；1618 以《七大恨》反明；1619 萨尔浒之战。
- 1631 皇太极仿明制设六部；1636 文馆改为内三院，并改国号「大清」、称帝、改元崇德、追尊父祖。制度建设有先后，不能全部压到 1636 年。
- **核心张力**：汗位与帝位是两件事；《七大恨》版本不一；国号「大清」的确立是一次成体系的「改朝」工程。
- **必读**：大事记 1—2 号；评传 1—2 号；解读 1—2 号（《七大恨》、改国号诏）。

### 第 2 期 · 入关定鼎（1644—1661）｜顺治

**一句话**：六岁即位，多尔衮摄政入关，完成从「关外政权」到「全国政权」的转变。

- 1644 入关迁都北京；剃发、圈地、逃人法引发南方反抗；亲政后追罪多尔衮。
- **核心张力**：顺治遗诏「渐习汉俗」的自责如何形成仍待取证；“经孝庄／辅臣修改”目前只能列为待核解释，不能压成定论。
- **必读**：大事记 3 号；评传 3 号；解读 3 号（顺治遗诏）。

### 第 3 期 · 盛世（1661—1796）｜康熙 · 雍正 · 乾隆

**一句话**：三代皇帝接力，把疆域、制度、文化推至鼎盛，同时埋下继承与文字狱的隐忧。

- 康熙：除鳌拜、平三藩、收台湾、三征噶尔丹、两废太子（继承是当前证据最密的一段）。
- 雍正：秘密建储、耗羡归公、军机处、文字狱与《大义觉迷录》。
- 乾隆：平准噶尔、编《四库全书》、六次南巡、禅位后训政三年。
- **核心张力**：康乾盛世的评价须并列成本（准噶尔人口灾难、文字狱禁毁书）；乾隆「禅位」实为「在位与执政分离」。
- **必读**：大事记 4—6 号；评传 4 号；解读 4 号（乾隆禅位诏）；康雍继承各章。

### 第 4 期 · 中衰（1796—1850）｜嘉庆 · 道光

**一句话**：内乱渐起、财政困顿，王朝由盛转衰，在鸦片战争中被迫开埠。

- 嘉庆：受内禅、诛和珅、白莲教、天理教攻宫。
- 道光：禁烟、第一次鸦片战争、《南京条约》。
- **核心张力**：道光的禁烟立场摇摆（禁烟→开战→议和）；「节俭」故事须核档。
- **必读**：大事记 7—8 号；评传 5—6 号；解读 5—6 号（诛和珅上谕、禁烟上谕）。

### 第 5 期 · 危局与转型（1850—1875）｜咸丰 · 同治

**一句话**：太平天国与第二次鸦片战争并作，圆明园被焚，皇权转向「太后垂帘」。

- 咸丰：太平天国、英法联军、避走热河、身后赞襄八大臣。
- 同治：辛酉政变、两宫垂帘、洋务运动、1873 短暂亲政。
- **核心张力**：咸丰顾命八大臣迅速破产；同治「中兴」是后出评价；死因疑云。
- **必读**：大事记 9—10 号；评传 7—8 号；解读 7—8 号（赞襄遗诏、亲政诏）。

### 第 6 期 · 新政与终结（1875—1912）｜光绪 · 宣统

**一句话**：甲午、戊戌、庚子、新政连环冲击下，王朝在「预备立宪」中走到终点。

- 光绪：甲午战争、戊戌变法、庚子之变、清末新政；遗诏的执笔与授意链条尚未完成取证。
- 宣统：载沣摄政、预备立宪、武昌起义、1912 退位。
- **核心张力**：光绪死因（砷中毒）下毒者未知；退位诏书把「结束帝制」包装成「还政于民」。
- **必读**：大事记 11—12 号；评传 9—10 号；解读 9—10 号（光绪遗诏、退位诏书）。

## 三、整朝主线速览

```
创业立国（1583—1644）   努尔哈赤 → 皇太极        十三副遗甲 → 大清立国
        ↓
入关定鼎（1644—1661）   顺治                   关外政权 → 全国政权
        ↓
盛世（1661—1796）       康熙 → 雍正 → 乾隆       疆域鼎盛 / 继承与文字狱隐忧
        ↓
中衰（1796—1850）       嘉庆 → 道光             内乱渐起 / 鸦片战争开埠
        ↓
危局转型（1850—1875）   咸丰 → 同治             太平天国 / 圆明园被焚 / 垂帘
        ↓
新政终结（1875—1912）   光绪 → 宣统             甲午戊戌庚子 / 预备立宪 → 退位
```

十二帝继承链连续（努尔哈赤→溥仪），每一期都标注「核心张力」——争议不是要掩盖的瑕疵，而是理解历史复杂性的入口。
