# 十帝评传（第一版 · 索引级）

> 帝王评传组第一版产出。范围：康熙、雍正之外的其余十帝（康雍已进入深挖，另见各卷正文）。
>
> **状态约定**：事实挂证据或标「待核」；评价标出处与立场（明确"这是史家评价，非事实"）；无证据的动机推断不入正文。数据源：`data/qing-emperor-research-cards.csv`（事件骨架、争议边界）、`data/imperial-works.csv`（文献）、`data/qing-emperors.csv`（骨架）。

---

## 1. 努尔哈赤（天命，1616—1626）

- **性格**：起兵创业之主。史籍赞语状其「神武」（评价，出《清史稿》本纪赞语，待核原文）；「十三副遗甲」起兵属叙事概括，非定量事实（待核）。
- **施政**：统一女真诸部；创制满文（1599，已回查）；整编八旗；建立后金（1616，已回查，国号后金非"大清"）。
- **功过**：萨尔浒之战奠定后金对明军事优势（事实，待核精确年月）；宁远之战受挫（1626，已回查）。「太祖」为后世追尊，非生前称号。
- **争议（学术）**：汗号与后世皇帝称号的时态区分；宁远炮伤与死因；前三朝实录反复改写。

## 2. 皇太极（天聪；崇德，1626—1643）

- **性格**：强化汗权、集中权力的创业者（据施政举措推定，标「推定」）。
- **施政**：仿明制设六部（1631）、文馆改内三院（1636）；满文加圈点（1632，已回查）；改族称女真为满洲（1635，已回查）；称帝改国号大清（1636，已回查）；编蒙古八旗、汉军八旗；两征朝鲜；松锦之战。
- **功过**：改国号、定制度，为入关奠定政治框架（史家评价）；松锦之战重创明朝关外力量（事实，待核）。
- **争议（学术）**：1626 汗位与 1636 帝位必须分开（称号时态）；继位是推举还是预定；猝死原因。

## 3. 福临（顺治，1643—1661）

- **性格**：汉学修养与「渐习汉俗」的自责形成对照（据遗诏与《资政要览》，已回查文献）；亲政后追罪多尔衮（事实）。
- **施政**：1643 年福临即位后由济尔哈朗、多尔衮辅政，后来多尔衮居主导地位；1644 年入关迁都北京；剃发、圈地、逃人法与亲政后追罪多尔衮仍待逐条精确定位。不能从入北京才起算辅政／摄政。
- **功过**：完成清入关定鼎（事实）；剃发圈地引发南方反抗（史家评价）。
- **争议（野史）**：出家说不可当事实；董鄂妃身份争论；遗诏形成过程。

## 4. 弘历（乾隆，1735—1795；训政至 1799）

- **性格**：御制诗四万余首、自号「十全老人」（事实）；好大喜功为后世常见评价（评价，标"史家评价"）。
- **施政**：平准噶尔及天山南路（待核）；编《四库全书》（待核）；文字狱与禁毁书；六次南巡；马戛尔尼使团；禅位后训政。
- **功过**：疆域鼎盛（事实）；准噶尔人口灾难（争议，学术）；禁毁书数量（争议）。
- **争议（学术）**：出生地；「十全武功」评价；禅位后实际权力（1796—1799 在位与执政须拆分）。

## 5. 颙琰（嘉庆，1796—1820）

- **性格**：史料留存的性格描述有限（待核）。
- **施政**：1796 内禅与训政已回《清史稿》卷15、16；1799 年壬戌太上皇崩、丁卯和珅下狱、丁丑赐死已分日（见 `#/chapter/jiaqing-04`）；整顿吏治、白莲教、天理教攻宫、阿美士德使团仍为索引。
- **功过**：清朝由盛转衰的过渡期（史家评价）；反腐叙事须拆制度与个案（争议）。
- **争议（学术）**：1796—1799 训政口径；猝死病因。

## 6. 旻宁（道光，1820—1850）

- **性格**：「节俭」故事流传甚广，但须核档（争议边界明确标注，待核）。
- **施政**：即位（1820，已回查）；避讳改名绵宁→旻宁（制度程序）；禁烟与林则徐；第一次鸦片战争；《南京条约》及后续条约。
- **功过**：鸦片战争失利、开埠（事实）；禁烟到开战的政策摇摆（争议）。
- **争议（学术/野史）**：继承竞争故事多后世加工；孝静成皇后追尊过程。

## 7. 奕詝（咸丰，1850—1861）

- **性格**：史料留存的性格描述有限（待核）。
- **施政**：即位（1850，已回查）；太平天国与捻军；启用曾国藩及地方军；第二次鸦片战争；天津、北京条约；圆明园被焚掠；避走热河；身后赞襄政务安排。
- **功过**：内忧外患并作（事实）；对外失败责任须区分皇帝决策与制度责任（争议）。
- **争议（学术）**：北狩与逃离北京的叙述立场；两宫印章与八大臣权力设计（不能以后来权势倒推慈禧咸丰朝影响）。

## 8. 载淳（同治，1861—1875）

- **性格**：六岁即位、亲政短暂（事实），个人施政空间有限（评价）。
- **施政**：即位（1861，已回查）；辛酉政变、两宫垂帘（待核）；镇压太平军、捻军及西北起事；洋务运动；1873 亲政（已回查）。
- **功过**：「同治中兴」为后出评价，不能当已核政绩单（争议边界）。
- **争议（野史）**：官方死因天花、梅毒说多晚出；真实决策空间；阿鲁特氏死因；「祺祥」仅拟用年号。

## 9. 载湉（光绪，1875—1908）

- **性格**：戊戌变法中的能动性存争议（争议，学术，不可简单归为"帝党"）。
- **施政**：即位（1875，已回查，过继）；中法战争；新疆建省；甲午战争；戊戌变法与政变；义和团、八国联军、辛丑条约；清末新政。
- **功过**：变法未成、国势倾颓（事实）；帝党/后党不可直接实体化（争议边界）。
- **争议（学术）**：生辰异文须以玉牒核；现代检测支持急性砷中毒但下毒者未知；甲午主战与戊戌决策能动性。

## 10. 溥仪（宣统，1908—1912）

- **性格**：三岁即位，幼帝行为不能归于本人（边界明确）。
- **施政**：即位（1908，已回查）；载沣摄政；预备立宪、皇族内阁；铁路国有与保路运动；武昌起义；退位（1912，已回查）。
- **功过**：清帝退位、王朝终结（事实）。
- **争议（学术）**：1908 即位 / 1909 纪年 / 1911 王朝终 / 1912 退位四种口径并存；无清朝庙号谥号；1917 复辟与伪满帝位非清朝连续在位。
