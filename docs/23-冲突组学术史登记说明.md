# 23 · 冲突组学术史登记说明

> 生成日期：2026-09-11。对应 `docs/21` 的 P0 第三项「冲突组补学术史综述」。
> 改动对象：`data/conflict-sets.csv` 追加三列（`研究综述`、`主要论著`、`综述状态`），既有六列文字未作任何改动。

---

## 一、为什么要加这三列

原冲突组表只记录**本库自己的编辑判断**（`现行编辑判断`、`保留意见`），读者看不到「这个问题学界怎么看」。结果是两种风险：

1. **把本库的处理方式误当学界共识。**「不择一、分层保存」在康熙继位、雍正死因等问题上确有学术依据，但依据没写下来，看起来就像编辑的回避。
2. **无法回答读者最常问的「有没有相关研究」。** 有些争议早有专文（如胤禵改名之争），有些确实无人做过（如卷164表序）——这两种情况应当被区别对待。

新增三列：

| 列 | 内容 |
|---|---|
| `研究综述` | 该争议的学术脉络：有哪几派、各自主张什么、论据是什么、目前是否取得一致 |
| `主要论著` | 可核查的书目条目：作者、书名或篇名、发表载体、出版信息 |
| `综述状态` | `已登记` / `部分` / `待补`，并注明还缺什么（多为版次与页码） |

---

## 二、登记标准（诚实边界）

本列不是「文献综述」的替代品，其可靠性受以下四条约束，使用时须一并考虑：

1. **只登记能核实的书目信息。** 本轮对核心书目做了外部核实（作者、书名、译者、出版社、出版年、ISBN）。**凡未能核实的出版信息一律不写**，不凭印象补全。
2. **页码一律不写。** 页数是最容易编造、也最容易被发现的信息。全表 9 条 `已登记` 的条目均标「版次页码待补」，含义是：**书目可靠，页码尚未逐页核对**。引用前须自行取书核对。
3. **区分「有专文」与「无专文」。** 无专文的写 `待补`，并在同一格内写明**须查什么**（如「须查《清史稿》卷15、卷16影印本与独立历法库」），而不是留空。
4. **转引须可辨。** 部分观点（如吴秀良、陈熙远、张双志、沈一民之说）本轮系经中文学术综述转述而后登记，未直接核对其原文；因此这几条在 `主要论著` 中只列篇名、不列页码。

## 四、与 CAL-001 校验的交叉发现

`QH-CF-QL-JQ-ABDICATION-GANZHI`（嘉庆元年正月朔干支）在本轮 `npm run check:calendar` 中**被独立命中**（见 `docs/22` §4.1）：同一公历日 1796-02-09 被赋予 `戊申` 与 `戊辰` 两个干支。该检查事先未被告知此冲突组的存在，也未产生其他误报，可作为方法可靠性的一次外部验证。

**同时暴露一处待修的缺口**：该冲突组有 4 条主张引用受争议表达，但只有 2 条挂了组 ID——

| QH-A-QL-0001 | 嘉庆元年正月戊申朔 | `QH-CF-QL-JQ-ABDICATION-GANZHI` ✓ |
| QH-A-QL-0002 | 嘉庆元年正月戊申朔 | **（空）** |
| QH-A-JQ-0001 | 嘉庆元年正月戊辰朔 | `QH-CF-QL-JQ-ABDICATION-GANZHI` ✓ |
