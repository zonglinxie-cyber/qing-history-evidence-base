## 1. 三表列结构（模板）

### 1.1 后妃时态轴

```
event_id,person_id,当时称号,事件类型,原纪年,公历下界,公历上界,来源单元,引文,回查状态,冲突组 ID,主张 ID,排序键,备注
```

- `当时称号` 是该时刻的称号，不是最终谥号；`事件类型` ∈ `册立/册封/晋封/生育/崩逝/初谥/改谥/安葬/尊封/时态说明`。
- 同一人多次变称号 = 多行，每行一条来源。死后累加谥号只能记 `改谥`，不能倒写进生前。
- 「世宗即位尊 X 为皇太后」这类跨朝事件，原纪年写「世宗即位」，公历区间给宽，不放在康熙朝在位皇后逻辑里。

### 1.2 皇子表

```
person_id,表序,表序标签,收录状态,规范名,世表用名,异名,父亲ID,生母人物ID,生母候选名,生母来源,世表摘要,后妃传子女句,证据状态,冲突组 ID,排序键,备注
```

- `收录状态` ∈ `入序正文 / 早薨附列 / 本卷缺号`。
- `表序` 是世表编号，≠ 自然序；早薨未入序者单列 `早薨附列`，`表序` 留空、`排序键` 用 `9X` 区。
- `世表摘要` 与 `后妃传子女句` 必须是卷内原文（繁体照录），不是转述白话；没有原文就留空并标「待回查」。
- 生母一律写「当时位号 + 姓/名」，如康熙表用 `惠妃纳喇氏` 而非最终谥号；生母候选 ≠ 已定生母，靠 `生母来源` 指向卷次。

### 1.3 皇女表

```
person_id,表序,表序标签,收录状态,规范名,公主表用名,异名,父亲ID,生母人物ID,生母候选名,生母来源,封号摘要,下嫁摘要,生薨摘要,额驸事略,证据状态,冲突组 ID,排序键,备注
```

- `收录状态` ∈ `入序受封 / 未封 / 抚育附列`。
- 封号分层：`初封 / 进封 / 追进固伦` 分开记，追封必须在薨后（康熙表把「雍正元年追进固伦温宪」写清，不许写成生前）。
- 抚育女不是亲生，`父亲ID` 写生父，`收录状态` 记 `抚育附列`。

## 3. 建行纪律（状态口径见 docs/04 §2）

- 未回原文前，`世表摘要 / 引文` 字段**不得**出现仿原文，只能留空并标「待回查」。
- 建行后主张状态由自审（`npm run self-review`）维护：有逐字引文＋卷页定位＋无冲突组才进「已采纳」。
- 生母、追封、死因、立储/遗诏等敏感行：有冲突即挂冲突组或标存疑，并进 STATUS.md「建议顺手抽查」清单。
